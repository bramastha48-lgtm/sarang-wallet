# WLLT-e - Smart Financial Dashboard

Dashboard keuangan pribadi yang lengkap dan mudah digunakan. Kelola dompet, catat transaksi, pantau keuangan, dan capai tujuan hidup lebih mudah & terarah.

![WLLT-e Dashboard](https://img.shields.io/badge/WLLT--e-Smart%20Financial%20Dashboard-orange?style=for-the-badge)

## ✨ Fitur

- **🏠 Dashboard** - Overview keuangan harian, mingguan, bulanan
- **💰 Multi Dompet** - Kelola bank, e-wallet, dan uang tunai
- **📝 Transaksi** - Catat pemasukan & pengeluaran dengan mudah
- **📊 Anggaran** - Budgeting dengan sistem 50/30/20
- **🎯 Financial Goals** - Target tabungan dengan progress tracking
- **💎 Aset** - Monitor kekayaan bersih (net worth)
- **📋 Hutang** - Lacak cicilan dan jadwal pembayaran
- **💵 Piutang** - Kelola uang yang dipinjamkan
- **📈 Investasi** - Portofolio saham, crypto, obligasi
- **📊 Laporan** - Skor kesehatan finansial & grafik analisis
- **🤖 AI Assistant** - Chat dengan AI untuk insight keuangan
- **📷 Scan Struk** - AI-powered receipt scanning (UI)
- **🔄 Langganan** - Track subscription bulanan

## 🛠️ Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with CSS Variables, Flexbox, Grid
- **JavaScript** - Vanilla JS, no framework dependencies
- **Chart.js** - Interactive charts & graphs
- **Font Awesome** - Icons
- **Google Fonts** - Inter font family

## 🚀 Cara Pakai

1. Clone repository:
```bash
git clone https://github.com/YOUR_USERNAME/wllte-app.git
cd wllte-app
```

2. Buka `index.html` di browser, atau gunakan live server:
```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

3. Akses `http://localhost:8000`
